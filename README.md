# Notre projet

L’objectif de ce rapport est d’analyser différentes transformations appliquées à une image numérique, afin d’observer leur impact sur les niveaux de gris, le contraste et les détails visuels.
L’image utilisée pour cette étude est `cathedrale.jpg`, qui présente des zones sombres et lumineuses variées, ce qui permet d’évaluer efficacement les effets des différentes méthodes.

Pour plus de détails concernant le projet, vous pouvez consulter `Rapport Image.docx`
